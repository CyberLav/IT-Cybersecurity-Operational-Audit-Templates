# Evidence Request Tracker Template 

A template  for tracking the lifecycle of audit artifacts. This tracker ensures that every piece of evidence logs, configurations, screenshots, or interview data is formally requested, received, and validated

| Request ID  |  REQ \- 01 |
| :---- | :---- |
| Risk Reference  | RISK \- 01 Governance |
| Test Procedure   |  2 |
| Description  | *Detailed requirement for the artifact.*  |
| Owner  | *Primary client contact responsible for the data* |
| Date Requested | *Date the request was issued (for SLA tracking)* |
| Status | Lifecycle state: Pending, In-Progress, Received, Validated |
| Evidence Path | *URI/Link to the secure storage repository* |
