# **Finding Log Classification Tool**

An interactive, browser-based audit utility for classifying and documenting security findings using a standardized **Impact × Likelihood** severity matrix.

### **Objective**

This tool removes subjectivity from risk reporting. By enforcing a strict 5×5 classification logic, it ensures that every finding is rated consistently, creating a defensible audit trail that aligns with organizational risk appetite.

### **Core Features**

| Feature | Description |
| :---- | :---- |
| **Automated Logic** | Calculates risk scores (1–25) and assigns severity (Critical/High/Med/Low) instantly. |
| **Evidence Ready** | Captures Finding ID, Audit References, and Rationale for audit working papers. |
| **Data Persistence** | Browser-based storage keeps your work safe between sessions—no server backend required. |
| **Audit Export** | One-click export to timestamped CSV for reporting and Management Action Plans. |
| **Dynamic Workflow** | On-demand row management for scalable audit logs. |

### **How It Works**

1. **Input**: Select an **Impact** (1–5) and **Likelihood** (1–5) score per finding.  
2. **Calculate**: The tool automatically maps the product to an embedded 5×5 risk matrix.  
3. **Document**: Attach the context, Finding ID, and rationale directly in the row.  
4. **Export**: Download the completed log as a CSV for use in final reports or remediation tracking.
